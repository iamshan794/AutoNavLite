AutoNav-0 is an offline-first, open-source 2D Mars map and route planner. A headless C++ service (autonav0d) serves cached NASA Trek tiles, MOLA elevation, risk-aware A* routes and Mars24 solar geometry to this lightweight client.

Data: NASA Solar System Treks (JPL/Caltech), NASA PDS (MGS MOLA MEGDR), USGS/IAU Gazetteer of Planetary Nomenclature, NASA/JPL MMGIS rover traverses, NASA GISS Mars24 algorithm. See CITATIONS.md.

Route estimates use ~463 m MOLA data and are planning aids only — they cannot see rocks, ventifacts or sand ripples below orbital resolution.
